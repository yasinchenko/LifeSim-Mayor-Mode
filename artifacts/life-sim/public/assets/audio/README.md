# Audio asset slots

The UI expects these files:

- `city/city-morning.mp3`
- `city/city-day.mp3`
- `city/city-evening.mp3`
- `city/city-night.mp3`
- `system/incident-alert.mp3`
- `music/main-menu-theme.mp3`
- `music/music-1.mp3`
- `music/music-2.mp3`
- `music/music-3.mp3`

Missing files are tolerated by the audio runtime, so the game can run before final audio is added.

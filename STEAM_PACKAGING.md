# Steam packaging checklist

This project now has a desktop build path for Steam-style Windows packaging.

## Build outputs

- `pnpm run desktop:build` builds the API, Vite frontend, and Electron main process.
- `pnpm run desktop:dist` also runs `electron-builder` and writes Windows output to `release/desktop`.

The Electron app starts the local API on `127.0.0.1` with a random free port, serves the built frontend from that API, and stores the SQLite save file in Electron's `userData` directory.

## Steam depot shape

For Steam, prefer uploading the unpacked Windows directory generated by the `dir` target:

```text
release/desktop/win-unpacked/
```

Set the Steam launch option executable to:

```text
LifeSim Mayor Mode.exe
```

The NSIS installer is useful for direct distribution, but Steam depots usually work best with an unpacked application directory.

## Local save data

The packaged app writes the save DB outside the install directory:

```text
%APPDATA%/LifeSim Mayor Mode/life-sim.sqlite
```

That keeps Steam updates from overwriting player saves.

## Before uploading to Steam

1. Run `pnpm install` after the dependency changes.
2. Run `pnpm run desktop:dist`.
3. Launch `release/desktop/win-unpacked/LifeSim Mayor Mode.exe`.
4. Verify first-run population generation, simulation start/stop/reset, settings changes, and app restart persistence.
5. Upload `win-unpacked` through SteamPipe as the Windows depot content.

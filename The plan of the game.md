1. MVP игрового режима ✅

выбор сценария;
цель партии;
лимит по игровым дням;
финальный экран победы/поражения.

2. Решения и последствия ✅

очки действий в день;
кулдауны указов;
персистентные отложенные указы;
видимый список активных эффектов.

3. Дилеммы ✅

расширить ежедневные события;
добавить долгосрочные побочные эффекты;
сделать карточки главным daily gameplay.

4. Фракции и давление ✅

требования жителей/бизнеса/власти;
штрафы за игнорирование;
награды за выполнение.

5. Игровой UI 

заменить часть аналитического дашборда на “центр управления”;
добавить экран дня;
карту сделать интерактивной;
добавить финальный отчёт партии.

6. Балансировка

настроить длительность партии;
проверить, что победа требует выбора, а не ожидания;
сделать несколько устойчивых стратегий: социальная, рыночная, силовая, коррупционная, балансная.

Главная идея: не переписывать симуляцию, а обернуть её в понятную игровую структуру. Движок уже умеет создавать последствия. Теперь нужно сделать так, чтобы игрок видел ставки, принимал ограниченные решения и получал выразительную реакцию города.
